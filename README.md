# 🚀 Login Page — Tailwind CSS

Interface de login responsiva desenvolvida com HTML5 e Tailwind CSS 4, utilizando uma ilustração de astronauta e uma identidade visual com tons de roxo e verde.

O projeto foi desenvolvido inicialmente com CSS tradicional e posteriormente adaptado para Tailwind CSS, permitindo explorar uma nova abordagem de estilização e construção de interfaces.

## 🖥️ Preview

! [https://prnt.sc/hhfewbfXOfxN]

## 🛠️ Tecnologias utilizadas

- HTML5
- Tailwind CSS 4
- Node.js
- npm

## ✨ Funcionalidades

- Interface de login com campos de usuário e senha.
- Layout responsivo para diferentes tamanhos de tela.
- Efeitos visuais nos campos de formulário.
- Botão de login com interação ao passar o mouse.
- Organização dos elementos utilizando Flexbox.
- Estilização com classes utilitárias do Tailwind CSS.

## 📱 Responsividade

O layout foi desenvolvido utilizando uma abordagem Mobile First, adaptando a disposição dos elementos conforme o tamanho da tela.

- **Mobile:** ilustração e formulário organizados verticalmente.
- **Desktop:** ilustração e formulário posicionados lado a lado.

## 📚 Conceitos praticados

- Instalação e configuração do Tailwind CSS.
- Utilização de classes utilitárias.
- Flexbox com Tailwind.
- Responsividade com breakpoints (`sm:` e `md:`).
- Cores personalizadas.
- Espaçamentos, bordas e sombras.
- Estados de interação (`hover:` e `focus:`).
- Compilação de CSS utilizando Tailwind CLI.
- Gerenciamento de dependências com npm.

## ⚙️ Como executar o projeto

1. Clone o repositório.
2. Abra a pasta do projeto no VS Code.
3. Instale as dependências:

   ```bash
   npm install
   ```

4. Inicie o compilador do Tailwind:

   ```bash
   npx @tailwindcss/cli -i ./tailwind.input.css -o ./tailwind.css --watch
   ```

5. Abra o arquivo `index.html` no navegador.
